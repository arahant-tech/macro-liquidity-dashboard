# 원자료 그래프의 수집·해석 규율

## 1. 무엇을 검증했는가

중앙은행·중국 신용·ACM 기간 프리미엄·FINRA 마진부채·TIC 주식 거래의 관측 이력을 현재 빈티지·원단위·원빈도로 표시하고, 원관측일을 과거 이용 가능 시각으로 오인하지 않는지 검증한다. 유동성 잠재상태를 추정하거나 예측력을 검증하는 작업은 아니다.

## 2. 스펙

| 원천 | 계열 | 확보 범위와 원빈도 |
|---|---|---|
| FRED 공식 API | WRESBAL, WALCL, ECBASSETSW, JPNASSETS, RRPONTSYD, WTREGEN | 최근 약 3년의 현재 빈티지. 일·주·월 원관측일 유지 |
| PBoC 공식 월간 표 | 총자산, 기타 예금취급기관 예금, TSF 잔액, TSF 월간 흐름 | 현재 보관된 공식 연도 표의 실제 발표 월. 첫 연결은 2026년 1~7월 |
| NY Fed ACM 공식 CSV | NYFED_ACM_TP10_MONTHLY | `TERMYld`, 미국 국채 10년 기간 프리미엄, percent. 월말 원관측일 유지; 월평균이 아님 |
| FINRA Margin Statistics 공식 HTML | FINRA_MARGIN_DEBT | `Debit Balances in Customers' Securities Margin Accounts`, million USD. 월말 고객 마진계좌 차입잔액 |
| 미 재무부 TIC SLT Table 1 공식 TXT | TIC_US_EQUITY_FOREIGN_NET_PURCHASES | Grand Total `99996`의 `for_lt_eqty_net`, million USD. 외국인 미국 주식 순매수 월간 거래; 보유잔액·평가손익이 아님 |

FRED는 `units=lin`, 당일 `realtime_start/realtime_end`를 사용한다. 집계 빈도나 계절조정 변환을 요청하지 않는다. 월간 날짜가 월초로 표시될 수 있어 조회 시작을 월초로 잡고 화면의 3개월·1년·3년 선택 범위에서 다시 제한한다. PBoC는 이번에 수집한 원문을 재검증하여 모든 공개 월을 읽는다. 최신 월 값이 같아도 과거 월의 개정은 반영한다.

ACM·FINRA·TIC는 `state/live/<provider>/latest.json`의 이번 실행 `sources` 영수증에서 공식 URL과 일치하는 원문을 선택한다. 원문의 SHA-256·파일 경로·원단위·표/열 식별·최신 관측과의 일치를 검증하며 네트워크를 다시 요청하지 않는다. 최신 관측 행에 남아 있는 이전 원문은 전체 과거 셀의 최신성을 보장하지 않으므로 선택 근거로 쓰지 않는다. 표시 범위는 최근 약 3년 중 최대 36개의 실제 월 관측이며, 유효 관측이 12개 미만이면 새 이력 생성을 거부한다. FINRA 표에 없는 이전 월은 채우지 않는다. TIC는 2023-02 구조 변경 이전 흐름을 이어 붙이지 않는다.

ACM의 날짜는 CSV에 적힌 실제 월말 영업일이다. FINRA의 달력 월말 날짜는 해당 월 마지막 영업일의 결제기준 잔액을 표시하는 월 레이블이며, 발표일이 아니다. TIC의 달력 월말은 해당 월 거래 흐름의 기간 종료일이다. 세 원천 모두 월말 날짜를 맞추기 위해 재표본화하거나 일별로 반복하지 않는다. TIC의 양수는 외국인의 순매수이며, 과거 월의 명시적 `n.a.`는 `null`로 남긴다. 최신 값이 없으면 이전 달로 조용히 대체하지 않는다.

각 계열의 단독 축을 사용한다. 통화 환산·국가 간 합산·고정 Net Liquidity 계수·기준 100 지수를 만들지 않는다. 표시 편의를 위한 백만/억→조 단위 변경만 정확한 원단위가 일치할 때 적용한다. 원단위 값은 그래프 아래 수치 표에 남긴다. TSF 월간 흐름은 0을 기준으로 한 막대이며 스톡은 원관측 사이를 연결한 선이다. 선 사이에 새로운 관측값을 만들지 않는다. 명시적 결측은 선을 끊고, 0은 유효값으로 남긴다.

`details.html`의 선택 그래프는 수집기의 13개 이력을 모두 지원한다. 새 계열을 수집기에 추가할 때 표시 정의가 빠지면 자동 검사에서 실패하도록 원천 목록을 대조한다. ACM 변화는 표시기간의 마지막 값에서 첫 값을 뺀 금리 차이로, percent 단위 차이에 100을 곱한 bp를 표시한다. 음수·0을 지날 수 있는 기간 프리미엄에 상대 변화율을 적용하지 않는다. FINRA 잔액은 양수인 첫 관측 대비 변화율이며 TIC·TSF 흐름은 월별 양·음 값을 0 기준 막대로 표시한다. 기간 버튼은 실제 확보된 관측만 선택하며 부족한 월을 채우지 않는다.

`known_by`는 전체 이력을 실제 확보한 시각이다. ACM·FINRA·TIC는 검증한 전체 원문의 수집 영수증 시각을 사용하고, 미래 시각·시간대 없는 시각·최신 관측기간보다 이른 확보시각을 거부한다. 같은 이력이면 최초 시각과 이를 입증하는 원문·해시를 함께 보존한다. 과거 셀 개정은 새 원문의 확보시각을 가지며, 경제적 관측월로 소급하지 않는다. 각 원문은 실행 아티팩트로 보존하고, 재시작에는 최신 이력과 연결된 원문만 유지한다. 이력 갱신 실패 시 이전 이력·원문·최초 확보시각을 함께 유지하며 `status=retained`로 표시한다.

수집은 기존 GitHub Actions의 매시간 실행에 포함한다. 공개 `chart-data.json`과 관측용 `live-data.json`을 분리하며 연구·홀드아웃 폴더를 쓰지 않는다. `research_eligible=false`, `vintage_policy=current_snapshot_not_historical_availability`를 기본값으로 고정한다.

## 3. 결과

기존 FRED 6개·PBoC 4개의 수집 경로를 유지하고 ACM·FINRA·TIC 이력 3개를 추가했다. 2026-09-09 저장 원문 검증에서 ACM 36개(2023-09-29~2026-08-31), FINRA 13개(2025-07-31~2026-07-31), TIC 34개(2023-09-30~2026-06-30)의 실제 월 관측을 추출했다. 최신 값은 각각 0.762512945770763 percent, 1,417,225 million USD, 181,426 million USD이며 기존 관측 행과 일치한다. 이 확인은 저장 원문에 대한 로컬 검증이며 새 수집이나 배포 완료를 뜻하지 않는다.

ACM·FINRA·TIC 원문 영수증 시각은 각각 2026-09-08 20:35:17.784723 UTC, 20:35:19.484076 UTC, 20:35:28.427869 UTC다. 이 원문에서 추출한 과거 월에 과거 공표시각을 부여하지 않는다. 단위 변화, 결측/0, 불완전 페이지, 미래 빈티지, 과거 셀 개정, 원문 해시·경로, 실패 후 보존, 원월 날짜·거래 부호·세계 합계 식별·12개 미만 이력 거부를 검사한다. 최신 성공 여부는 공개 화면과 연결된 실행 기록을 확인한다.

축1에서는 수집·표시의 재현성과 증거 보존만 검증한다. 잠재인자의 안정성·LOO는 미평가다. 축2 이벤트/NFCI, 축3 OOS·분위·경제적 유의성은 미산출이다. 축4의 신규 회귀 시도는 0이며, 홀드아웃을 갱신하지 않는다.

## 4. Kill criteria

모형의 여섯 기준은 미판정이다. 원자료 그래프가 정상 작동한다는 사실은 측정모형의 채택 근거가 아니다. 이 화면에서 인샘플 R²·자산가격 레벨 상관·진입 신호를 제시하지 않는다.

## 5. 가정과 깨지는 곳

가정: 각 원천의 계정 정의·단위와 현재 빈티지에 기록된 관측값이 정확하다. 이 데이터는 발표 당시 빈티지와 다를 수 있다. 현재 확보한 과거 월을 당시 이미 알았다고 가정할 수 없다.

깨지는 곳: 기관의 과거 개정, 발표 지연, 원자료 정의 변경, HTTP 장애와 GitHub 지연이 남는다. PBoC는 확보된 표보다 긴 이력을 채우지 않는다. 주·월 자료를 일간으로 반복하지 않는다. 기관별 총자산과 준비금은 다른 개념이며 카드 값을 가로로 더하거나 같은 유동성 상태의 직접 대체물로 해석하면 안 된다. 시각적 변화만으로 인과나 방향 예측력을 주장하지 않는다. 방향 예측에는 미래 유동성 자체를 예측해야 하는 문제가 남는다.

ACM은 NY Fed가 매월 재추정하는 모형 값이며 실제 조달금리나 전체 장기금리와 같지 않다. FINRA는 보고 회원사의 고객계좌 잔액으로 시장 전체 레버리지를 측정하지 않으며 차입 감소만으로 강제청산을 단정할 수 없다. TIC는 공표가 늦은 월간 외국인 거래이며 현재 주식 수요나 전체 종단 플로우를 확정하지 않는다. 서로 다른 관측월의 최신 값을 같은 날의 상태로 합성하거나 실시간 종합 판정에 자동 매핑하지 않는다.
