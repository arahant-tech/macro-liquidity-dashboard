# 대표 관측 화면과 조건부 종합 해석

## 무엇을 검증하는가

첫 화면은 준비금·재무부 현금·기간 프리미엄·마진 차입·외국인 미국주식 순매수의 실제 관측을 표시한다. 다섯 관측을 하나의 유동성 점수로 합치지 않는다.

## 입력과 갱신

`live-data.json`의 최근 관측과 `chart-data.json`의 원빈도 이력을 함께 사용한다. GitHub Actions가 매시간 원자료와 이력을 수집·게시하고, 브라우저는 5분마다 새 공개 자료를 확인한다. 시안의 고정 수치는 운영 페이지에 포함하지 않는다. 이력과 최근 관측의 기준일·값·단위 및 실행 기록이 일치해야 현재 해석에 사용한다.

| 관측 | 원빈도 | 첫 화면 범위 | 등락 |
|---|---|---|---|
| WRESBAL · Fed 준비금 | 수요일 종료 주간평균 | 최근 52개 원 관측 | 전주 증감액·증감률 |
| WTREGEN · TGA | 수요일 종료 주간평균 | 최근 52개 원 관측 | 전주 평균의 증감액·증감률 |
| NYFED_ACM_TP10_MONTHLY | 월말 관측 | 최근 13개 월 관측 | 전월 대비 bp |
| FINRA_MARGIN_DEBT | 월말 잔액 | 최근 13개 월 관측 | 전월 증감액·증감률 |
| TIC_US_EQUITY_FOREIGN_NET_PURCHASES | 월간 순매수 흐름 | 최근 12개 월 관측 | 전월 증감액 |

`WTREGEN` 변화는 주간 평균 잔액 간 차이이며 그 주의 재무부 순지출이 아니다. TGA 일간 입출금과 빌·쿠폰 발행/상환은 이 화면의 자동 판정 입력에 아직 포함되지 않는다. 전체 자료와 별도 크립토 트랙은 `details.html`에서 확인한다.

## 시점과 실패 처리

날짜·단위가 잘못된 이력은 그래프로 그리지 않는다. 결측은 0으로 채우지 않고 선을 끊는다. 비교 가능한 직전 관측이 없으면 등락을 보류한다. 현재 값만 확보되면 그 값을 표시하고 이력 미확보로 표시한다. 수집 실패·이전 정상값·원천 갱신 지연·최근값과 이력의 불일치는 현재 해석에 사용하지 않는다. 전체 수집이 3시간 이상 늦으면 운영 지연으로 표시한다. 이 기준은 수집 상태 기준이며 경제적 위험 임계값이 아니다.

브라우저 요청 실패 때에는 이전 화면과 원 수집시각을 유지한다. 새로 확인한 시각으로 원자료의 `known_by`를 덮어쓰지 않는다. 현재 빈티지는 과거 발표 시점에 알았던 자료를 인증하지 않는다.

## 종합 해석

현재 관측 문구는 지표별 기준기간을 표시한다. 7개 가정 시나리오는 별도 버튼으로 선택하며 현재 레짐으로 자동 분류하지 않는다. 시나리오 선택은 그래프 자료를 바꾸지 않는다. 조건·유리한 점·부담·다음 확인·가정·해석이 깨지는 곳·공식 출처를 함께 표시한다. 추가 확인 대상인 SOFR−IORB·레포·자사주 등은 그 상태가 확인됐다고 가정하지 않는다.

## 결과·Kill criteria

여기서 검증하는 것은 데이터 연결과 화면 동작이다. 계수/표준오차, 내적·구성·외적 타당성, 연구자 자유도 평가 및 여섯 kill criteria는 이 배포로 평가하지 않았다. L_t와 A_t는 미추정이다.

## 가정과 깨지는 곳

TGA와 준비금은 연결된 회계 경로이므로 독립 충격 두 개로 더하지 않는다. ACM은 실제 조달금리 자체가 아니며, FINRA 감소만으로 강제청산을 확정할 수 없다. TIC는 과거 월의 외국인 채널 관측이며 현재 전체 주식 수요가 아니다. 원빈도와 관측기간을 혼합하거나 미래 정보를 소급 사용하면 해석이 깨진다. 유동성 증가는 가격 상승의 충분조건이 아니며, 방향 예측에는 유동성 자체의 예측이 먼저 필요하다.
