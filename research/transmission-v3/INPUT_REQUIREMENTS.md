# 미검증 경로를 열기 위해 필요한 자료

## 당시 나스닥100 예상이익

현재 공개 입력에는 공표 시각이 있는 과거 나스닥100 예상 EPS 시계열이 없다. 해당 경로는 `unverified`다. 이후 자료를 확보하면 최소한 다음 필드가 필요하다.

- 기준 지수와 당시 구성·집계 방식: Nasdaq100, 주당 또는 지수 EPS의 단위.
- 예측 기준: 앞으로 12개월(NTM), 회계연도 FY1 등 고정된 전망 기간.
- 예상 EPS 값과 최초 공표/이용 가능 시각. 개정치마다 빈티지 식별자.
- 제공자와 출처, GAAP/조정이익 구분, 적자기업 처리 방법.

현재 가격÷후행 PER, 나중에 발표된 실현 EPS, 현재 컨센서스를 과거에 덮어쓴 값, S&P500 이익 자료는 당시 나스닥100 예상이익의 대체물이 아니다. 예상이익 자료 없이 금리·EBP 통제 후 남은 관계를 순수 유동성 효과라고 해석하지 않는다.

## 정책의 순수 잔액 충격

USMPD의 단기금리 선물 기반 고빈도 surprise는 정책경로에 관한 예상 수정이다. 순수 QE/QT 규모 surprise를 별도로 식별하려면 발표 직전 시장 예상 매입/축소 규모·만기구성과 실제 발표 내용을 같은 기준으로 갖춘 사건 자료가 필요하다. 실제 정책금리 변화나 FOMC 날짜 표시만으로 surprise를 대신 만들지 않는다.

## 준비금 부족의 독립 검증

SOFR/EFFR 스프레드, 금리 상단, 양의 스프레드 일수는 가격 압력의 대리변수다. 은행별 결제 지연·장중 당좌대월·조달 수량과 거래 분포 같은 독립 자료가 있으면 별도 검증이 가능하다. RDE는 준비금과 fed funds 자료를 사용한 외부 연구모형의 추정치이므로 독립된 정답으로 취급하지 않는다.
